### Projekte

**[enterprise-knowledge-guard](https://github.com/DanielHuette/enterprise-knowledge-guard)**
Internes Frage-und-Antwort-System auf Firmenunterlagen: die Zugriffsrechte liegen in PostgreSQL, nicht im Prompt.
pgvector-Suche und Zeilen-Rechte in einer Abfrage, ein Agent mit rollengebundenen Werkzeugen, 74 Tests gegen Datenlecks.
Läuft unter [enterpriseknowledge.speedofthespirit.dev](https://enterpriseknowledge.speedofthespirit.dev)

**[eu-ai-act-dsgvo-konformitaetshelfer](https://github.com/DanielHuette/eu-ai-act-dsgvo-konformitaetshelfer)**
Einstufung nach der KI-Verordnung (EU) 2024/1689 über eine Fragefolge statt über Raten.
379 belegte Fragen aus den Leitlinien der EU-Kommission, 207 von 217 amtlichen Beispielen richtig eingestuft.
Läuft unter [konformitaetshelfer.speedofthespirit.dev](https://konformitaetshelfer.speedofthespirit.dev)

**[autoteile-chatbot-schraubi](https://github.com/DanielHuette/autoteile-chatbot-schraubi)**
Auskunftshelfer für einen Gebrauchtteile-Versandshop, der Kunden ohne Teilenummer zum richtigen Teil führt.
Vektorsuche allein trifft in 50,7 % der Fälle; mit Volltext, Bauteilerkennung und Mindestähnlichkeit sind es 93,2 % —
und der Anteil, bei dem ein falsches Teil obenauf liegt, fällt von 49,3 % auf 1,9 %.

**[Multilingual_YouTube_Analyzer](https://github.com/DanielHuette/Multilingual_YouTube_Analyzer)**
Production-grade RAG system for multilingual question answering over YouTube video content.
Abschlussprojekt des Ironhack AI Bootcamps. Python, LangChain, OpenAI Whisper, ChromaDB, Gradio.

Audio-Bitrate, Embedding-Modell, Sprachmodell, Chunk-Größe, RAG gegen kein RAG.
